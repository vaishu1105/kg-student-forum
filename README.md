# KG Student Forum

KG Student Forum is a student-focused discussion and collaboration platform designed to help students connect, share ideas, discuss academic topics, and access learning resources through an interactive and user-friendly interface.

The project was developed with a focus on responsive UI/UX design, accessibility, and clean frontend structure to create a smooth user experience for engineering students.

---

## 🚀 Features

- Student discussion forum
- Responsive and modern UI
- User-friendly navigation
- Interactive frontend design
- Academic discussion sections
- Community-based interaction
- Scalable structure for backend integration

## 🎨 UI/UX Design Process

Created low-fidelity wireframes to plan:
- Layout structure

- User interaction

### Prototyping
Developed interactive prototypes in Figma to simulate:
- User journeys
- Page transitions
- Responsive layouts

### User Experience Focus
- Simple navigation
- Minimal design
- Clean typography
- Consistent color hierarchy
- Mobile-friendly layouts
